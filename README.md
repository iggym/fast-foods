# fast-foods

> A starter repository for fast food–related projects — menus, nutrition data, ordering apps, or anything else on the menu.

## Getting started

```bash
git clone https://github.com/iggym/fast-foods.git
cd fast-foods
```

This repo is currently a clean scaffold. Drop your source into `src/` (or the root), add dependencies,
and start building.

2. Create a feature branch: `git checkout -b feat/my-feature`

4. Push the branch: `git push origin feat/my-feature`
5. Open a pull request

Commit messages in this repo loosely follow [Conventional Commits](https://www.conventionalcommits.org/).
